# Southern Iowa Home Connect

Development repository for **Southern Iowa Home Connect**, a local home-services connection/referral website for Southern Iowa.

## Current launch plan

- **First live category:** Septic
- **Initial planned area:** Appanoose, Davis, Lucas and Monroe counties
- **Future categories:** Roofing, plumbing, HVAC, tree service, fencing, concrete, electrical, junk removal, landscaping, well services and garage doors

## Development status

The website is currently in **pre-launch / preview mode**. Forms intentionally do not transmit homeowner information yet.

## Pages

- `index.html` — main site and service directory
- `septic.html` — first service landing page
- `privacy.html` — pre-launch privacy placeholder
- `terms.html` — pre-launch terms placeholder
- `404.html` — fallback page
- `styles.css` — global responsive design
- `app.js` — navigation and preview-form behavior
