# Southern Iowa Home Connect

A mobile-first local lead-generation and provider-directory platform for Southern Iowa home services.

## Model
- Structured homeowner matching
- Participating provider directory
- Local service/town/county pages
- Homeowner guides for organic search
- Contractor onboarding and future lead monetization

## Current status
Pre-launch preview. Forms do not transmit/store information. No provider affiliation, ratings, availability, verification or reviews are fabricated.

## V2 implemented
- Conversion-focused homepage with service + location finder
- 7-step matching flow
- 12 category pages
- Browse Providers shell
- 4 town + 4 county pages
- Homeowner guide hub + starter guides
- FAQ
- For Contractors + application preview
- Provider standards
- Privacy/terms
- Mobile sticky CTA
- Analytics event hooks
- SEO sitemap/robots
- Central JSON data files

## Before live lead collection
1. Connect a custom domain.
2. Configure secure backend/storage.
3. Add anti-spam protection.
4. Finalize privacy/terms with actual vendors and contact info.
5. Recruit/verify providers.
6. Configure routing + notification rules.
7. Add production analytics/conversion tracking.
8. Add billing only after qualified-lead rules are finalized.
